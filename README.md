# CopilotCal

CopilotCal je jednoduchý osobní týdenní kalendář běžící přímo v prohlížeči. Zobrazuje týden od pondělí do neděle v hodinové časové ose, zvýrazňuje dnešní den a pracovní hodiny a umožňuje přecházet mezi týdny, filtrovat události podle kategorií a vytisknout týdenní rozvrh.

Události lze vytvářet kliknutím do volného časového slotu, zobrazit jejich detail, upravovat je a mazat. Formulář podporuje popis, datum a čas, kategorii, místo, prioritu, připomínku a týdenní opakování. Události a nastavení se ukládají do `localStorage`; při prvním spuštění se načítají ukázková data z `data/demo-events.json`.

Aplikace je napsaná v čistém HTML, CSS a JavaScriptu bez frameworků. Spustíte ji otevřením souboru `src/index.html`.
