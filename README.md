# CopilotCal

CopilotCal je jednoduchý osobní týdenní kalendář, který běží přímo v prohlížeči bez registrace a serveru. Umožňuje procházet týdny, vytvářet, upravovat a mazat události, filtrovat je podle kategorií a nastavit jejich prioritu, místo, připomínku nebo týdenní opakování.

Aplikace je vytvořená pomocí čistého HTML, CSS a JavaScriptu. Události i nastavení se ukládají výhradně do `localStorage` prohlížeče. Spustíte ji otevřením souboru [`src/index.html`](src/index.html).
